# 软糖情侣默契测试

一个适合手机玩的静态 H5 小测试。十道轻松题目，测测你们的情侣默契有几分甜，还可以把结果保存成卡片、复制分享文案。

纯静态 HTML/CSS/JS，无后端、无第三方库。插图来自「软糖双人」表情原画，已去掉白底并压缩。未使用 sheet2 第 5 格的绷带造型。

## 本地预览

在本目录启动任意静态服务器，例如：

```bash
cd /workspace/games/ruantang-moqi
python3 -m http.server 8769
```

然后用手机或浏览器打开 `http://127.0.0.1:8769/`。

## 说明

- 默契百分比由十道题的选项决定，同一组答案会得到同一结果；在分数上会有很小的固定偏移，避免总是整十的数字
- 称号共七档：灵魂伴侣、心有灵犀、甜蜜搭档、刚刚好的缘分、还在磨合中、反向默契担当、欢喜冤家
- 「保存图片」会下载卡片；在 iOS 或微信里如果无法直接下载，会弹出图片并提示长按保存
- 「复制分享文案」会写入剪贴板；如果环境不允许，会弹出文本框让你手动复制
- 页脚：作者 hukx · [请作者喝奶茶](https://afdian.com/a/hukxai)

## 本地检查

```bash
node --check js/app.js
python3 -m http.server 8769
# 另开终端：
node tools/screenshot.mjs
```

`tools/screenshot.mjs` 会用注入脚本打开开始页、题目页和结果页（不依赖页面上的调试 URL 参数），截图写到 `/tmp/ruantang-shots/`。
